## 1. Project Summary

Completed development and deployment of the Process Qualification module (PRVALID) v1.1.0 for Ascent Circuits Private Limited (ACPL). The system provides 4M qualification (Man, Machine, Material, Method) through test plan creation, multi-stage verification and approval, qualification execution with conditional and final release, revalidation scheduling, and automated email notifications. Built on ASP.NET Core 8.0 with SQL Server database integration.

---

## 2. Final Deliverables

- Test Plan Validation for New Validation (Man, Machine, Material, Method) with team assignment, file uploads, and plan submission
- Test Plan Revalidation with qualification-type selection and revalidation period tracking
- Two-Stage Plan Approval Workflow (Verification and Approval with reject/resubmit and email notifications)
- Qualification Execution (trials, process/product characteristics, Qualified / Not Qualified decision)
- Conditional Release Workflow (verification and approval for Machine and Material)
- Final Release Workflow (submission, verification, and approval)
- Pending Actions queues (Plan Verification, Plan Approval, Qualification List, Conditional Verification/Approval, Final Release, Final Release Verification/Approval)
- Dashboard with financial-year filter, KPI cards, status/trend charts, and pending-action analytics
- User Access Control with role-based permissions (Module Admin / Can Create Plan)
- Man Qualification Master (employee, department, process/sub-process mapping)
- Integration with ACPL Common Database for employee, machine, process, and item master data
